# Anti-Slope

Help the author read and understand AI-generated work before handing it over. Minesweeper is the first implemented workflow.

For code, read `minesweeper/SKILL.md` relative to this file and follow it. That skill uses the existing local runtime/UI and a private, independent exercise generator. Collaborative analysis uses its reader-visible discussion view. Exercise generation must use its private bridge; never prepare an exercise or inspect private answers in this conversation. Never load the generator reference into the primary conversation.

For design documents or other non-code work, explain that an Anti-Slope workflow is not implemented yet. Offer ordinary careful review only when the user wants it; do not pretend it is Minesweeper.

Review is voluntary and produces findings, evidence, dispositions, and unresolved questions. It produces no personal scores or automatic external messages. Preserve room for disagreement, no findings, incorrect references, and unclear requirements.
